# Bus Bell

Умные напоминания для общественного транспорта: приложение будит, когда вы подъезжаете к своей остановке.

## Что в репозитории

| Папка | Что это |
|---|---|
| `index.html` (корень) | Веб-версия: одна страница на React + Яндекс.Карты |
| `app/` | Мобильное приложение Bus Bell 2.0 на React Native / Expo (Android-сборка в APK) |

## Мобильное приложение (`app/`)

Expo SDK 50, React Native 0.73, TypeScript, zustand + AsyncStorage.

Возможности: карта с остановками и маршрутами из OpenStreetMap (Overpass API), поиск маршрута по номеру,
напоминания с радиусом и звуком, фоновое отслеживание геолокации, режим будильника, избранное, тёмная и светлая тема.

### Запуск для разработки

```bash
cd app
npm install
npx expo start
```

### Скачать APK на телефон

Открой репозиторий с телефона → **Releases** справа → последняя сборка → скачай `busbell.apk` и установи.
Android попросит разрешить установку из этого источника — разреши.

APK собирается автоматически в облаке GitHub (вкладка **Actions**, 10–15 минут) при каждом изменении папки `app/`.
Компьютер и аккаунт Expo для этого не нужны. Новая версия ставится поверх старой, напоминания сохраняются.

Сборки подписаны открытым тестовым ключом `app/tools/android/busbell-test.keystore` — он годится только для тестов.
Для Google Play нужен собственный секретный ключ, который не хранится в репозитории.

### Сборка через Expo (EAS) — по желанию

Проект также привязан к EAS (Expo), `projectId` указан в `app/app.json`.

```bash
npm install -g eas-cli
cd app
eas login
eas build -p android --profile preview     # APK для установки на телефон
eas build -p android --profile production  # AAB для Google Play
```

Готовые сборки лежат на expo.dev → проект **busbell** → Builds.

### Что нового в 2.1.0

- Будильник срабатывает и при заблокированном экране: отдельный канал уведомлений с громким звуком
  (`alarm.wav`, тип «будильник»), зацикленный звук и вибрация запускаются прямо из фоновой задачи.
- Кнопка «Отключить» прямо в уведомлении.
- Настоящая длинная вибрация (`Vibration`) вместо коротких тактильных щелчков.
- Будильник больше не глушится сам сразу после срабатывания; фоновый сервис работает, пока будильник не выключен.
- Нет двойных срабатываний: фоновая задача и обычное отслеживание используют одну проверку.
- Кнопки «Тест вибрации» и «Тест будильника» в настройках проверяют настоящие вибрацию и звук.
